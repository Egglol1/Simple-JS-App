# Project Description

A list of all 150 pokemon from the Gen 1 games. Each pokemon can be clicked on for informtion about its types, abilities, and id.

# How to use

To run, open in Github pages, to run locally, open index.html

# Included technology

Uses javascript version ES6, ESLint rules, as well as a promise and fetch polyfill for unsupported browsers

Uses this external API https://pokeapi.co/api/v2/pokemon/?limit=150
